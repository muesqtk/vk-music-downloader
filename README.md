# VK Music Downloader

Небольшое GUI-приложение (Python + Tkinter) для скачивания **своей** музыки из ВКонтакте
через официальное API (`audio.get`).

## Возможности

- Загрузка всей фонотеки пользователя по токену VK: программа дочитывает все страницы,
  даже если VK отдаёт их неполными (раньше список обрывался на ~200 треках).
- Плейлисты: кнопка «Плейлисты…» открывает список ваших плейлистов с поиском; выбранный
  плейлист загружается в таблицу и скачивается как обычный список треков.
- Таблица треков: исполнитель, название, длительность, статус.
- Поиск по исполнителю и названию, сортировка по столбцам.
- Отметка треков галочками (клик по первому столбцу или пробел).
- Скачивание отмеченных или всех треков: прогресс-бар, журнал, настраиваемое число
  параллельных загрузок (1–8, по умолчанию 4).
- Проверка, что скачался действительно аудиофайл: заглушки VK, HTML-страницы ошибок и
  обрезанные файлы больше не сохраняются под видом музыки.
- Если VK отдаёт HLS/DASH-плейлист (`m3u8`/`mpd`) вместо mp3, трек собирается через `ffmpeg`.
- Пропуск уже скачанных файлов (включается галочкой); повреждённые файлы перекачиваются.
- Настраиваемый шаблон имени файла: `{artist}`, `{title}`, `{album}`, `{id}`, `{owner_id}`, `{duration}`.
- Автоматическая запись ID3-тегов (исполнитель/название/альбом), если установлен `mutagen`.
- Обновление устаревших ссылок на файлы через `audio.getById` при ошибке 403/410.
- Кнопка «Стоп» и сохранение настроек (папка, шаблон, число потоков, токен — по желанию).

## Установка

Нужен Python 3.8+ (с Tkinter, в стандартной сборке для Windows он есть).

```bash
pip install requests mutagen
```

`mutagen` необязателен — без него программа работает, но не прописывает теги.
`ffmpeg` нужен только в случае, если VK отдаёт ссылки на HLS/DASH-плейлисты:

```powershell
winget install Gyan.FFmpeg
```

После установки перезапустите терминал (или добавьте папку `bin` с `ffmpeg.exe` в `PATH`).

## Запуск

```bash
python vk_music_downloader.py
```

## Как получить токен

1. Создайте Standalone-приложение: <https://dev.vk.com> → «Мои приложения» → «Создать».
2. Скопируйте ID приложения и откройте в браузере ссылку, подставив свой ID:

   ```
   https://oauth.vk.com/authorize?client_id=ВАШ_ID&display=page&redirect_uri=https://oauth.vk.com/blank.html&scope=audio,offline&response_type=token&v=5.131
   ```

3. Разрешите доступ. Откроется пустая страница `blank.html` — скопируйте из адресной
   строки значение `access_token=…` (до символа `&`).
4. Вставьте токен в поле «Токен» и нажмите «Загрузить мою музыку».

Токен хранится в файле `%USERPROFILE%\.vk_music_downloader.json` и только если включена
галочка «Запомнить токен». Файл не шифруется — не оставляйте его на общих компьютерах.

## Плейлисты

Нажмите «Плейлисты…», найдите нужный плейлист по названию, выберите его и нажмите
«Загрузить треки» (или дважды кликните по строке). Треки появятся в основной таблице —
дальше с ними можно работать как обычно: искать, отмечать, скачивать.

## Число параллельных загрузок

В нижней части окна есть поле «Параллельных загрузок» (1–8). Значение сохраняется в
настройках и применяется при следующем запуске скачивания. Больше потоков — быстрее, но
VK может начать ограничивать запросы; 3–4 обычно оптимально.

## Ограничения

- С 2017 года ВКонтакте ограничивает доступ к аудио для сторонних приложений. Если VK
  возвращает треки без поля `url` или вместо файлов присылает заглушки, скачать их через
  API нельзя — это ограничение на стороне VK, и программа его не обходит.
- Метод `audio.get` возвращает аудио текущего пользователя. Чужие фонотеки и плейлисты
  требуют отдельных прав и в этой версии не поддерживаются.
- Ссылки на файлы временные; если скачивание запущено спустя долгое время после загрузки
  списка, программа попробует получить свежую ссылку автоматически.

## Если скачивание не работает

Программа не сохраняет всё, что прислал сервер, а проверяет содержимое. В журнале видно,
что именно вернул VK:

- `получено 3 КБ вместо музыки (Content-Type: audio/mpeg)` — VK прислал заглушку;
- `VK вернул не аудиофайл (... Content-Type: text/html)` — вместо файла пришла страница
  ошибки или капчи;
- `VK вернул заглушку audio_api_unavailable` — у токена нет доступа к треку.

После трёх таких треков подряд загрузка останавливается, чтобы не создавать сотни мусорных
файлов. Причина — доступ токена к аудио: с 2017 года VK ограничивает `audio` для сторонних
приложений, и программа это ограничение не обходит.

Если в журнале упоминается `плейлист (m3u8/mpd)`, установите `ffmpeg` — см. раздел «Установка».

## Правовая заметка

Скачивайте только свою музыку или контент, на который у вас есть права. Использование
программы не отменяет условия использования ВКонтакте и требования законодательства об
авторском праве.
